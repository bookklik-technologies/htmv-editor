## Design Specificity Verdict

Authored, not interchangeable (code-enforced three-token economy, local-first voice, iOS grouped surfaces, honest LOCAL WORKSPACE framing). Deductions: template-preview side-tab accent (the one token bypass) and the export dialog's liability-waiver copy.

## Priority Issues

1. **[P0] Keyboard-only users cannot select a timeline clip** — `timeline.ts clipHTML()` emits `role="button" tabindex="0"`; `editor.ts keydown()` maps Space to play and has no Enter handler; `click` delegate honors only `[data-action]`/`[data-select]`. A tabbed clip does nothing on Enter. No `aria-selected`. Fix: Enter/Space selects (Shift/Ctrl range-toggle) + `aria-selected` on selected clips.
2. **[P1] Re-importing a .htmv archive of a previously stored project permanently blocks autosave** — `storage.ts:56` treats `expected === undefined` + existing row as conflict; baseline only seeded by `storage.load()`. User sees misleading "Changed in another tab". Fix: adopt baseline when stored row deep-equals the incoming document.
3. **[P1] Errors are invisible as errors** — statusbar diagnostics render as muted 10px gray polite text; no severity styling; recovery dialog offers Retry/Save-a-copy/Download paths that all fail for missing-media projects (`validateProject` strict in save + `writeArchive`). Fix: severity styling + `assertive`, and relink guidance for the missing-media case.
4. **[P1] Fixed px row heights clip content at 150–200% text zoom** — clip 42px/22px name bar at 10px type, track 55px, statusbar 30px; violates the product's own minimum-workspace + zoom expectations. Fix: em-based `min-height`.
5. **[P1] Powerful shortcut set has zero in-tool discoverability** — S, I, O, Ctrl+D/G, Alt+arrows exist; no sheet, no kbd hints in tooltips.

## P2 findings

- Export dialog: 10 simultaneous decisions + jargon ("Temporary disk storage → download", "(128 MiB maximum)", unverified-audio legal paragraph).
- Dialog close button styled as green primary (reads as confirm, acts as cancel).
- Alignment row: 8 single-strategy text buttons incl. "distribute-x/y".
- Ctrl+wheel zoom (0.25–5×) never reflected in the 1–300% zoom select; pixel-handle compensation drops the fit-scale factor.

- Delete key mid-drag throws in `pointerEnd` commit path (non-null derefs after the clip was removed).
- `updateProject` unconditionally `endGroup()`, killing the focused-field undo group for callers that route through it.
- `.he-template-1` side-tab accent `#00ff99` @ styles.css:195 (true detector positive); trim-grip + locked-lane hatch detector findings are false positives.
